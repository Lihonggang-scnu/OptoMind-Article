# TMM research and design result

## Problem interpretation

Design a planar multilayer dielectric filter on a fused silica substrate with unspecified material incidence for an optical detection module. The filter should minimize average transmittance at 355 nm and in the 355-365 nm and 1030-1080 nm bands while maximizing average transmittance in the 420-700 nm band. Constraints include 0 deg incidence, unpolarized light, materials limited to Ta2O5 and SiO2, maximum 36 layers, and individual layer thickness between 20-350 nm. Compare different stack designs and analyze trade-offs between passband loss and dual stopband suppression.

## Method research

- **Dual-Filter Suppression Stacking**: Combine two separate multilayer filters with adjacent suppression bands to achieve broader wavelength suppression than a single filter can provide. Each filter targets a portion of the desired suppression range, and their combined transmittance achieves the full suppression goal.
- **Interlayer Graded Index Structure**: Replace discrete multilayer interfaces with graded index interlayers that vary composition gradually between high and low index materials. This reduces interface discontinuities and can improve antireflection performance at target wavelengths.
- **Modified Quarter-Wavelength Optimization**: Start with quarter-wave optical thickness layers (lambda0/(4*n)) for high-reflection bands, then vary optical thickness of selected layers away from quarter-wavelength values through optimization procedures to smooth spectral characteristics and broaden suppression bands.
- **Symmetric Mirror Cavity Tuning**: Construct bandpass filters using two symmetric dielectric mirror stacks (typically 5 layers each) separated by a resonance cavity layer. Tune center wavelength by adjusting only the cavity thickness while maintaining mirror layer thicknesses constant across multiple filter designs.
- **Software-Assisted Needle Technique**: Use needle optimization algorithm incorporated into thin-film design software to optimize multi-wavelength high-reflectance coatings with non-quarter-wave optical thicknesses. This enables complex 38+ layer designs targeting multiple wavelengths simultaneously.
- **Wavelength-Dependent Material Pairing**: Select different material pairs for different spectral regions based on absorption and refractive index properties. For UV region near 400 nm, use MgO with high-index material; for visible region, use SiO2 with high-index material. This optimizes filter performance for each target wavelength.
- **Alternating Layer Bragg Stack with Cavity**: Construct interference filters using alternating high-low index layer pairs (Bragg reflectors) with a central cavity layer. Typical structure: 5 alternating layers, thick central layer, then 5 alternating layers. Layer thicknesses around 80 nm for visible wavelengths.
