# TMM research and design result

## Problem interpretation

Design a planar multilayer dielectric film on a fused silica substrate with unspecified material incidence, using only HfO2 and SiO2, with a total layer count not exceeding 30. The design should maximize transmission in the 1000-1700 nm band and maximize reflection in the 300-450 nm band for a SWIR camera protective window.

## Method research

- **multi_objective_regularized_optimization**: Use transfer matrix method to propagate plane wave through alternating layer stack, initialize layer thicknesses randomly, define objective function with regularization parameter to balance competing spectral targets (e.g., maximize transmission in one band while maximizing reflection in another), apply nonlinear optimization with total thickness constraint
- **bounded_global_optimization_quarter_wave**: Parameterize layer physical thickness between 0 and lambda0/4 where lambda0 is reference wavelength, use LHLH or similar alternating configuration, apply global optimization to explore large configuration space, set target transmittance with tolerance band evaluated at discrete wavelengths across spectral range
- **quarter_wave_stack_protective_capping**: Use quarter-wave optical thickness layers as building blocks in alternating high-index and low-index materials, terminate stack with double quarter-wave optical thickness of low-index material as outermost layer for environmental and laser damage resistance
- **memetic_algorithm_optimization**: Combine evolutionary algorithm with local optimization to fine-tune material selection and layer thickness for each layer in multilayer structure, begin with randomized layer thicknesses from materials library, iteratively refine to achieve target emissivity or transmittance profile
- **angle_tuned_stopband_positioning**: Use incidence angle to tune stopband position in periodic multilayer structure, employ HL repeating unit with defined order, calculate angle dependence to position multiple reflection bands at target wavelengths, use fused silica substrate with backside reflectance excluded from calculation
