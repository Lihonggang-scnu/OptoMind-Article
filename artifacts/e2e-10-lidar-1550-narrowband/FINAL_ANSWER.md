# TMM research and design result

## Problem interpretation

Design a planar multilayer dielectric filter for a 1550 nm coherent LiDAR receiver front-end. Incident medium is unspecified material, substrate is Fused Silica. Materials are limited to Ta2O5 and SiO2. Total layers must not exceed 30. Target high transmittance (soft target ≥ 0.95) at 1550 nm. Strongly suppress background radiation in 1400-1500 nm and 1600-1700 nm bands.

## Method research

- **Quarter-wave DBR with Defect Cavity**: Structure DBR as (HL)^N D(LH)^N where H and L are high/low index materials with quarter-wave optical thickness nH*dH = nL*dL = lambda0/4. Insert defect layer D with half-wave optical thickness nD*dD = lambda0/2 to create transmission peak. Use large index contrast materials for highest defect mode intensity.
- **Needle Technique with Gradual Evolution**: Use needle optimization technique incorporated into thin-film design software for non-quarter-wave thickness optimization. Define merit function targeting specific spectral ranges (e.g., high transmission in passband, low transmission in stopbands). Can handle complex multi-wavelength targets with band width requirements.
- **Dielectric Mirror Cavity Structure**: Construct filter as Fabry-Perot interferometer with two dielectric mirrors separated by resonance cavity layer. Each mirror contains multiple dielectric layers (typically 5 or more per mirror). Cavity thickness characterized by multiple-beam interference causing high optical transmission in narrow wavelength band around wavelength where cavity is one-half wavelength thick.
- **Layer Sensitivity Weighting Method**: Evaluate wavelength shift contribution incrementally as discrete layers throughout multilayer using design-specific weighting factor assigning sensitivity to individual layers. For dual material filter, center wavelength shift described by sum over layers with material weighting factors for low and high index materials. Alternate layers can oppose each other to reduce temperature dependence.
- **Empirical Index Substitution**: Replace constant refractive index values in initial designs with measured n and k values from actual deposited films. Re-optimize initial designs using these empirical indices. Control thickness errors within 0.5% range using quartz crystal monitoring during deposition.
- **Multi-period DBR Stack**: Design broadband reflectors using 36 or more alternating high/low index layers. Use TMM method for simulation and comparison with experimental spectra. Adjust layer thicknesses to match target reflectance profile across wide spectral range.
