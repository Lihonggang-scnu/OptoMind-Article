# TMM research and design result

## Problem interpretation

Design a planar multilayer dielectric coating on a fused silica substrate with unspecified material incidence, using only HfO2 and SiO2, with a total layer count not exceeding 30. The goal is to maximize transmission in the 1530–1565 nm band and maximize reflection in the 400–700 nm band.

## Method research

- **Bounded Global Configuration Search**: Define a fixed alternating layer sequence (for example LHLH), constrain physical thickness between 0 and lambda0/4, and use global optimization to evaluate a large configuration space against a transmittance target.
- **Statistical Fabrication Error Simulation**: Simulate random layer thickness and refractive index errors (for example 2% RMS) within a transfer-matrix model to quantify performance degradation and verify spectral features persist under fabrication tolerances.
- **Needle Synthesis Optimization**: Use needle optimization algorithms to refine layer thicknesses beyond quarter-wave values, allowing for complex spectral targets with non-quarter-wave optical thicknesses.
- **Neural Network Inverse Design**: Train a tandem neural network model to predict layer thickness sequences from a target transmission spectrum, utilizing a forward model to map thickness to spectrum for training data generation.
