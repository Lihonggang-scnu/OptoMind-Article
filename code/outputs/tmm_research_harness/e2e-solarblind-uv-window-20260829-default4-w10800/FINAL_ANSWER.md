# TMM research and design result

## Problem interpretation

Design a front-end filter coating for a solar-blind UV ozone and high-altitude combustion plume detector on a low-orbit space platform. The detector requires maximum transmission of the 255–280 nm solar-blind UV signal, while suppressing the 300–700 nm visible background and 700–1100 nm near-infrared stray light. Conditions: unspecified material incidence, fused silica substrate, no metal layers, only conventional depositable inorganic dielectric materials, planar multilayer film, total layers not exceeding 30.

## Method research

- **Periodic Stack with AR Matching**: Construct a filter using periodic main-function units (L/2 H L/2) m sandwiched between two anti-reflection coatings. Optimize layer thicknesses using Transfer Matrix Method to define stopband and passband. L and H represent low and high refractive index layer thicknesses.
- **MDF Stack for Red-Leak Suppression**: Use metal layers separated by transparent dielectric spacers to form a bandpass filter. This architecture suppresses visible and infrared radiation (red-leak) while preserving ultraviolet transparency.
- **ALD or IAD for Index Stability**: Employ Atomic Layer Deposition or Ion-Assisted Deposition to produce dense, pinhole-free films. This minimizes moisture-induced refractive index shifts and ensures thickness uniformity.
- **TMM Optimization with Experimental Constants**: Optimize filter structure using Transfer Matrix Method based on experimental optical constants (n, k) measured via ellipsometry rather than nominal bulk values. This accounts for deposition-specific variations near material bandgaps.
