# TMM research and design result

## Problem interpretation

Design a planar multilayer dielectric film on a fused silica substrate with unspecified material incidence for a high-altitude UAV SWIR remote sensing camera window. Materials restricted to HfO2 and SiO2. Total layers must not exceed 30. Objectives: Maximize transmission in 800-1500 nm band and maximize reflection in 200-400 nm band.

## Method research

- **Needle Optimization Technique**: Use needle optimization algorithm to refine non-quarter-wave layer thicknesses for multi-wavelength high-reflectance targets. Define performance bands with minimum bandwidth (e.g., 30 nm per wavelength) and add protective outermost SiO2 layer of at least 200 nm for environmental durability.
- **Heterostructure Graded Index Design**: Implement graded index structures by incorporating interlayers between discontinuous high-low index interfaces. Alternate HfO2 and SiO2 layers starting with high-index on substrate and ending with low-index. Use composition cycle ratios to vary intermediate layer refractive indices for smoother index transitions.
- **Double-Layer Capping for Laser Resistance**: Build high-reflection mirrors using quarter-wave optical thickness alternating HfO2 (high-index) and SiO2 (low-index) layers. Terminate design with double quarter optical thickness of low-index material (2L) as final layer to improve laser radiation resistance.
- **CNN-LSTM Tandem Network for Thickness Prediction**: Use CNN-LSTM tandem neural networks for inverse design where target transmission spectrum serves as input and layer thickness sequence is predicted as output. Train on alternating high-low index layer structures with thickness ranges (e.g., 30-70 nm) and discrete thickness intervals.
- **Genetic Algorithm for Material-Thickness Co-Optimization**: Apply genetic algorithm with selection, mutation, and crossover operations to optimize both material type and layer thickness simultaneously. Index candidate materials and allow algorithm to select appropriate materials per layer position up to maximum layer count constraint.
- **Triple-Layer Quarter-Half-Quarter Design**: Implement triple-layer interference films with quarter-half-quarter wavelength optical thickness (lambda/4-lambda/2-lambda/4) structure. Middle half-wave layer broadens antireflection spectral range. Top layer should have low refractive index for air interface matching.
- **Alphanumeric Layer Sequence Notation**: Use alphanumeric string format with special symbols (round, square, curled brackets) to define layer sequences. Support three representation types: quarter-wave stack notation (e.g., SLH(ML)2), physical thickness notation (e.g., SM[1000]L[50]), and advanced designs with scaling factors.
