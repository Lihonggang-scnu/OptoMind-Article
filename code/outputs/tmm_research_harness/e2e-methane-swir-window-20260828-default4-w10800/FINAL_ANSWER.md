# TMM research and design result

## Problem interpretation

Design a planar multilayer dielectric coating on a fused silica substrate with unspecified material incidence using only HfO2 and SiO2 materials. The coating should maximize transmittance in the 1000-1700 nm band and maximize reflectance in the 300-450 nm band. The total number of layers must not exceed 30.

## Method research

- **Needle Optimization Technique**: Use needle optimization algorithm incorporated into thin-film design software to optimize non-quarter-wave optical thickness multilayer structures for multiple discrete wavelengths simultaneously. Each working wavelength should have a band with minimum width specification (e.g., 30 nm) for feasibility and repeatability.
- **Global Optimization with Bounded Thickness**: Apply global optimization strategy exploring large configuration space (e.g., 2e8 configurations) with layer thickness bounded between 0 and lambda0/4 where lambda0 is reference wavelength. Evaluate transmittance at discrete wavelengths uniformly distributed across spectral range. Select designs using merit function threshold with tolerance allowance (e.g., 1% tolerance on 100% target transmittance).
- **Interlayer Graded Structure**: Incorporate interlayers between discontinuous interfaces in multilayer stacks to create graded refractive index profiles. Start with high-index material (HfO2) on substrate, follow with alternating layers, end with low-index material (SiO2). Refractive indices of intermediate layers vary due to distinct composition cycle ratio.
- **Bilayer Stack Theory with AOI Specification**: Use alternating high-index and low-index quarter-wave layers where reflectivity maximizes for minimum layer count when optical thickness equals n*t = lambda/4. Layer on top should be higher refractive index material. For oblique incidence, specify angle (e.g., 45 degrees) in quarter-wave thickness calculation. Use notation system like (xH yL) repeated blocks for layer sequence.
- **Outermost Layer Protection**: Set outermost layer as low-index material (SiO2) with minimum thickness specification (e.g., >= 200 nm) to obtain better environmental durability. This applies regardless of underlying stack optimization method.
- **Analytical Tolerance Model**: Use analytical model to evaluate optical response and explore sensitivity of nominal design parameters to fabrication tolerances. For single-layer AR between vacuum and substrate with refractive index n, perfect cancellation at normal incidence occurs when layer refractive index equals sqrt(n) and thickness provides quarter-wavelength optical delay. Compute reflectance using recursion relation for m dielectric layers.
- **Protective Sealing Layer Integration**: Include thin sealing layer (e.g., 3 nm Al2O3) to protect coating from water penetration. Optimize multilayer design taking into account the top sealing layer influence. Due to low thickness, sealing layer has minimal impact on spectral transmittance.
