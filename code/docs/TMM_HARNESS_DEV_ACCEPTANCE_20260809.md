# TMM 光学实验 Harness 开发集验收

日期：2026-08-09  
范围：仅使用传输矩阵法（TMM）；不接入 RCWA、FDTD 或 FEM；唯一允许的策略模型为 `qwen3.7-flash`。

## 验收结论

开发题 `DEV01` 至 `DEV05` 已全部通过。每道题均完成一次正式运行，并在隔离目录中重新计算；两次运行的科学产物逐项一致。保留题 `HOLDOUT06` 至 `HOLDOUT10` 未运行、未产生结果、未参与代码或参数调整，等待用户随机抽测。

需要如实说明：访问审计安装前，旧的结构测试曾机械解析过保留集 JSON，以检查数量和字段，但没有运行题目，也没有把问题正文或运行结果反馈给调参过程。现已删除这种测试方式；普通测试仅用临时生成的假保留集验证权限逻辑。自访问审计启用以来，真实保留集读取事件为 0。

系统遵循以下规则：

- 设计目标只产生连续评分和排序，不作为“必须达到”的硬门槛。
- 物理接纳只由材料适用范围、无源性、能量守恒、光谱收敛和独立 TMM 交叉验证决定。
- 多样性只是一项可选加分，不是交付条件。只有当不同方案在性能上仍有价值且确实存在结构差异时，才增加“特色方案”。
- 如果同一个厚度方案同时是性能最佳、最稳健和最易制造的方案，多个角色可以指向它，不会强行制造次优设计。
- 材料库出现多个同等级数据页时，可将其作为有上限的不确定性场景。场景差异影响评分、排序和解释，但不会成为性能硬门槛。
- 预算耗尽时停止新增计算，同时保留已经通过物理验收的候选；如果没有任何物理可信结果，则关闭失败，不能伪装完成。

本轮“正式运行 + 隔离复算”总耗时约 76.1 秒，Qwen 调用为 0。主要科学抽查结果如下：

- DEV01 找到约 111.04 nm 的减反层。性能、稳健性和易制造性角色均指向同一最优候选；系统没有为了多样性保留数值克隆。
- DEV02 的 DBR 反射峰超过 0.99，并呈现合理的角度与偏振响应。
- DEV03 在约 1569.75 nm 附近解析到高透射缺陷模，并输出相位、群时延和群时延色散。
- DEV04 的最佳软目标得分由 0.399514 提升至 0.467519。该任务确实找到了性能接近但厚度结构不同的候选，因此额外保留了稳健、易制造和结构特色方案。
- DEV05 正确执行混合相干/非相干计算。由于缺少完全独立的混合相干参考实现，证书标记为 `physically_valid_with_limits`（物理有效但存在已说明的验证边界），没有伪装成无限制验证。

## 多样性规则的最终解释

`diversity_required=false` 已写入机器可读验收报告。候选组合的核心优先级为：

1. 目标评分高；
2. 物理验证可靠；
3. 对厚度、角度和材料数据扰动稳健；
4. 在不显著牺牲前三项的前提下，才考虑结构差异。

因此，DEV01、DEV02、DEV03 和 DEV05 可以只交付一个真正有价值的结构；DEV04 因为确实存在非克隆且有用的权衡方案，才提供多个候选。这是预期行为，不是候选不足。

## Qwen 策略约束

此前的独立轻量验证已确认真实调用可用：

- 实际模型：`qwen3.7-flash`
- 输入约 405 tokens，输出约 87 tokens
- 估算成本约人民币 0.001506 元
- 模型回退关闭，实际没有调用其他模型

Qwen 只能从确定性程序给出的动作白名单中选择策略，不能生成光谱、修改 TMM 数值、签发物理证书或改变保留题答案。五道开发题不需要 Qwen 也能完成，说明确定性物理内核不依赖模型维持正确性。

## 自然语言任务编译入口

新增 `QwenTMMTaskCompiler`（TMM 任务编译器），仅使用 `qwen3.7-flash` 将自然语言填入固定的 `OpticalDesignTask` 协议：

- 最多生成 3 个 TMM 实验；
- 只允许平面、各向同性、频域平面波问题；
- 超出 TMM 能力时返回 `needs_higher_fidelity`（需要更高保真求解器），而不是编造结果；
- 信息不足时返回 `needs_clarification`（需要澄清）；
- 非法 JSON 或协议错误最多修复 1 次，仍失败则关闭失败；
- 模型不能修改物理验收、预算上限、多样性规则或把性能目标变成硬门槛。

真实 DEV01 端到端测试中，编译器 1 次调用成功，约 1482 输入 tokens、936 输出 tokens；随后 Harness 完成仿真和优化，得到 3 个物理有效候选。生成的任务正确包含单层常折射率减反膜、500–600 nm 光谱范围、厚度边界、1 nm 量化和软目标。

盲测运行器为 `scripts/run_tmm_harness_holdout_acceptance.py`。它要求命令参数和环境变量双重授权；首次读取前写入审计日志。中断恢复使用已保存的选题和编译任务，不会再次打开保留集。
