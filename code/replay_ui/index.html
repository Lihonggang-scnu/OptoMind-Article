WHAT WILL HAPPEN

提交之后

  1. 锁定问题与指标从题面选择 VeriTMM 可计算的动态波段指标，并固定评分公式。
  2. 生成并比较路线文献启发路线和不接收文献的记忆对照路线并行研究。
  3. 执行真实仿真任务编译后交给 VeriTMM，候选经过物理核验再进入评分。
  4. 根据结果再规划逐轮观测决定继续、修正或停止，所有状态进入证据链。
  5. 进入静态回放完成后自动加入运行档案，可从最终结论回到每一轮原始文件。
