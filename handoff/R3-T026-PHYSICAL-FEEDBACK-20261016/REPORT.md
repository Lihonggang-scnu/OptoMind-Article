G1 是 450–650 nm 按波长积分后的平均反射率，G2 是 700–1000 nm 平均透过率；均为 45°、s/p 等权非偏振。逐路线完整数值见 [MEASURED_RESULTS.md](MEASURED_RESULTS.md)，谱线及证书见 `cache/runs`。

第二轮 R1 的 G1/G2 为 `0.623703/0.658484 → 0.329034/0.383207`；R2 为 `0.657017/0.693612 → 0.598298/0.674257`；R5 为 `0.497582/0.530717 → 0.497582/0.530717`。两个实际干预均使两个目标下降；R5 没有干预，不能证明增加周期有效。

在本次相同物理设置下，第二轮所有已评价结构的两个目标均被已有首轮结构同时超过。这里只比较实际算过的有限候选，未定义任意权重，也不宣称全局最优。不能把工程可运行或物理核验通过称为设计性能达标，也没有收益提升的证据。

最明确的观察利用轨迹：首轮 R2 用 12 层交替结构把 TiO2 从 60 nm 改到 80 nm、SiO2 保持 95 nm，G1 从 `0.885780` 降到 `0.635041`，与原“增加”预测相反。模型明确提及这个大幅下降，随后提出“较温和非对称”方案。但新基线为 `75/105 nm`，候选为 `82/95 nm`，不是原结构的连续单参数修订；再次计算 G1 从 `0.657017` 降到 `0.598298`，G2 也下降。能证明模型读到并提及观察，不能证明其物理解释正确或决策改善。
