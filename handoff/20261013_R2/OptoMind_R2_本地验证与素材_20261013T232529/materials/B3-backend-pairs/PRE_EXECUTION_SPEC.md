# B3 / E09 基础可比性小实验冻结 SPEC

**冻结时间：** 2026-10-13（Asia/Shanghai）  
**批次：** `B3-backend-pairs`  
**目的：** 对同一组平面相干 TMM 输入，仅切换 NumPy 与 Torch CPU 数值后端，验证 R/T/A 数值可比性。

## 冻结边界

- 源仓库：`D:\OptoMind-Article-3\repos\VeriTMM`，目标 HEAD：`dd9f27bf7b3f8150fdb37dc65f169ef6aab333f1`。
- 仅调用现有 `tmm_engine.backends.numpy_backend.assemble` 与 `tmm_engine.backends.torch_backend.assemble`；不改生产源码、分支、提交、历史数据或 F 盘。
- 两个后端接收同一个 Python `KernelSpec` 对象、同一个 `nk_stack` 数组、同一个厚度数组、同一个波长网格、同一个角度和偏振。Torch 固定 `dtype="float64"`、CPU；NumPy 使用 `complex128/float64`。
- 5 个任务均为有限层、平面、相干 S 矩阵 TMM。禁止 RCWA、FDFD、硬件、外部 API、依赖安装和外部网络。
- 评价器固定为同一个后处理：将 R、T 转为 `float64` 数组，并按 `A_eval = 1 - R - T` 计算 A；逐波长比较 NumPy/Torch 的 R、T、A。后端返回的 A 另存为审计字段，不替代公共评价器。
- 每个后端每个任务只执行一次顶层 `assemble`，公共评价器每个结果执行一次；每次单独捕获异常并继续其余任务。时间为单次墙钟 `perf_counter`，只用于记录，不作为 E09 收益证据。

## 冻结判定与指标

- **主指标 1（数值）：** 所有任务、所有网格点和 R/T/A 三个通道的最大绝对差 `max_abs_delta <= 1e-8`。不使用相对误差替代，不放宽阈值。
- **主指标 2（执行）：** 两后端每任务顶层调用数均为 1，公共评价器调用数均为 1；记录单次时间、总时间和内部偏振分支数。该指标描述执行记录，不宣称收益。
- **主指标 3（完整性）：** 10 次后端执行和 10 次公共评价均无异常；若异常或阈值失败，批次为失败并保留全部原始证据。

这只是数值后端可比性实验，不是“传统工具 vs AI 友好耦合”的比较，也不证明 E09 要求的 `>=30%` 收益。后端实验模型数固定为 **0**；本批次不产生真实物理模型、实测数据、制造证据或 AI 自主设计。合成 forward-computed 结果若存在，必须在所有结果和图中明确标记为 `synthetic forward-computed`。
