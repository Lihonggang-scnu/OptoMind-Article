# T027：把物理反馈接到实际数值搜索

状态：云端离线验证完成后发布本地联测。基准为 T026 `5786e08575b19020a6aece338436406884d3542d`。未通过本地真实材料与 Qwen 联测前，不称为性能验收。

## 为什么改

T026 的真实结果表明，模型读到了反馈，但没有保持好的搜索起点。首轮 12 层 60/95 nm 的 G1/G2 为 0.885780/0.802619；增大高折射率层厚度到 80 nm 后双目标下降。第二轮却换成 75/105 nm 基线，再提出 82/95 nm，仍然双降。已有首轮结构同时超过全部次轮结构。传递观察与形成有效决策是两件事。

本轮重点是把数值工作真正接入研究过程，保留原候选、原目标和原物理条件：

1. **保留已有优秀结构。** 认证结构进入多目标非支配档案，保存完整物理输入、父设计和实际改变。后续失败不会替换历史好解；同一缓存结果不会重复算成新证据。
2. **结构思路与厚度搜索分工。** 候选提供材料顺序、固定层、变量绑定和范围。工具在这个明确结构族内搜索厚度；LLM决定接下来从哪个父结构、按哪种参数化继续探索。共享变量仍共享，逐层自由细化必须显式声明为新参数化。
3. **工具主动提供能影响动作的信息。** 保存全光谱，同时生成全部原目标、蓝/中/红子区间的收益损失和真实 s/p 差异。诊断与目标评分分开；不能把正确预测下降当作优化成功。缺数据时不编造机制。
4. **搜索与认证分开。** 数值搜索可以快速筛选，但其输出只是待认证候选。独立认证通过后才可更新正式档案；所有尝试的搜索设计行、差分探针与失败都纳入数值预算，认证评价另外计数。

## 数值方法与边界

- 复用现有 VeriTMM 材料采样和实际 TMM 求解；有 PyTorch 时使用可微 TMM 的解析梯度，无 PyTorch 时使用原生 NumPy 求解与计数完整的数值差分。
- 有界 L-BFGS-B 多起点搜索，辅以空间填充起点。多个标量化方向用于探索目标权衡，不代表替用户指定最终偏好；正式保留集合按全部原始指标计算非支配性。
- 家族模式保留重复厚度变量的绑定和字面固定层。逐层细化仅解绑原来可变的层，沿用各层对应的原变量范围，不擅自改变材料、层数或固定层。
- 当前不新增针式插层、自动删层、跨材料拓扑搜索、制造公差实验、长期经验库。它们不是本次已经完成的能力。
- 有限预算的局部与多起点优化不保证全局最优，也不保证每条路线进步。工具应返回实际找到的、包含历史父结构的最好权衡集合。

## 物理反馈如何约束下一轮

每个后继计划必须定位已认证父设计。模型获得紧凑指标与诊断，给出具体观察依据、待检验解释、下一步方向及预期。程序执行有界的结构族优化或明确的逐层细化，不要求模型再次手写一整套厚度数值。

例如发现加厚后红端收益伴随蓝端损失，系统可继续探索非均匀厚度自由度，但必须以实际优化和复算结果判断；这条谱形观察本身不证明某个唯一物理机制。s/p 分解用于诊断界面与偏振响应，不能用错误的“各向同性层 s/p 传播相位不同”替代数值证据。

## 与 Claude 讨论后的取舍

在既有 Claude 网页会话讨论了父结构继承、多方向数值 polish、物理诊断与互补结构搜索。采纳前面三项和显式参数化分支；复杂插层/分组拓扑留待后续。Claude 给出的 Bragg 中心常数折射率粗估、预算比例和“匹配层修复某段”等均只作为假说或建议，没有写成程序判定事实，也未用模型意见替代测试。

## 可以怎样讲清技术价值

可展示一条真实链路：文献或经验提出结构族 → 工具在约束内并行认证与数值搜索 → 主动返回子波段/偏振损失 → 模型选择明确父结构及下一项细化 → 再搜索与认证 → 旧好解与新权衡共同保留。

若收益主要来自数值优化，应明确归因于数值优化接线。若模型改变参数化后获得额外收益，再用同一真实父子链展示这种贡献。不能把“调用优化器”本身宣称为全新优化算法，也不能把精选路线的结果称为平均水平。
